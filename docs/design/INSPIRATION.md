# Design inspiration

A living list of products, sites and books worth looking at when a Fork screen gets designed or revisited. Add a line when something catches your eye; say what to look at, not just the name. Judge everything against `DESIGN.md`; the warm annotated-cookbook direction stays. Sources in the last column are the docs that first cited the item (`research/…`), so the fuller note is one hop away.
