Recipe editor: groups, yield, audience

The paste-first editor stays: one box for ingredients, one for steps. A line starting with # names a group, and a read-back line under each box shows how Fork split it, so the cook can see and correct the interpretation before saving. Yield gets its own optional field beside servings. The public checkbox becomes an explicit two-way audience choice. Nothing else moves.
